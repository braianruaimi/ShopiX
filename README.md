## ShopiX

Landing page e-commerce de una sola página con estética high-tech, navegación por categorías, CTA directos, soporte PWA y experiencia optimizada para mobile.

## Qué incluye

- Hero principal con branding ShopiX
- Menú superior fijo para navegar categorías
- Secciones de productos destacadas
- Botones CTA directos
- PWA instalable
- Service worker para caché básico
- Diseño responsive para Android y iPhone

## Archivos principales

- index.html: estructura principal de la landing
- js/app.js: interacciones de UI, PWA, carrusel y navegación activa
- sw.js: caché y actualización de la app
- manifest.json: configuración instalable de la PWA

## Uso local

Podés abrir index.html directamente en el navegador o publicarlo con GitHub Pages para usarlo como acceso rápido desde el celular.
